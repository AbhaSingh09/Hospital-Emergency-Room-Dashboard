# Hospital Emergency Room Dashboard

## 1. Project Title
Hospital Emergency Room Dashboard

## 2. Purpose
A healthcare analytics dashboard designed to monitor **emergency room performance, patient demographics, and operational efficiency**.  
The purpose is to provide hospital administrators with actionable insights into patient flow, wait times, satisfaction, and referral patterns.

## 3. Tech Stack (Key Technologies Used)
- Power BI / Tableau / Excel (for visualization)
- SQL (for querying and preparing patient data)
- Python / Pandas (for preprocessing, if applicable)
- GitHub (for version control and documentation)

## 4. Data Source
- Hospital Emergency Room dataset (monthly patient records for July 2024)  
- Includes fields such as **Patient ID, Age, Gender, Race, Admission Status, Wait Time, Satisfaction Score, Referral Department, Day & Hour of Visit**

## 5. Features 
- **Business Problem:** Hospitals need to track ER efficiency, patient satisfaction, and demographic distribution to improve healthcare delivery.  
- **Goal of Dashboard:** Provide a **monthly view** of ER operations to identify bottlenecks, improve patient care, and optimize resource allocation.  
- **Key Visuals:**
  - KPIs: No. of Patients, Avg Wait Time, Satisfaction Score, No. of Patients Referred
  - Patient Admission Status (Admitted vs Not Admitted)
  - Patients by Age Group
  - % of Patients Seen Within 30 Minutes (Target vs Missed)
  - Patients by Gender
  - Patients by Department Referral
  - Patients by Race
  - Patients by Day & Hour (heatmap + bar chart)
- **Business Impacts & Insights:**
  - Track wait times and identify delays in patient care
  - Monitor satisfaction scores to improve service quality
  - Understand demographic trends (age, gender, race)
  - Optimize staffing by analyzing patient flow by day and hour
  - Identify departments with high referral rates (e.g., General Practice, Orthopedics)
